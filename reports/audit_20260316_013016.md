#### C1: Diagnostic Script Exposes Database Structure

**Severity:** CRITICAL  
**Location:** `scripts/debug/diagnostic.php`  
**CWE:** CWE-200 (Information Disclosure), CWE-489 (Active Debug Code)

**Description:**
The diagnostic script reveals database structure and connectivity status. While guarded by `APP_DIAGNOSTIC_MODE=1`, this is insufficient protection because:
1. The file exists in the production codebase
2. An attacker with any code execution can set the environment variable
3. Reveals table names that aid SQL injection targeting

**Attack Scenario:**
```
1. Attacker gains minor code execution (e.g., through any vulnerability)
2. Sets APP_DIAGNOSTIC_MODE=1 via putenv()
3. Accesses /scripts/debug/diagnostic.php
4. Learns all table names: users, transactions, activity_logs, login_attempts
5. Crafts targeted SQL injection payloads with known schema
```

**Current Code:**
```php
// scripts/debug/diagnostic.php
if (getenv('APP_DIAGNOSTIC_MODE') !== '1') {
    echo "Diagnostic mode disabled.\n";
    exit(0);
}
// ... reveals all database tables ...
```

**Recommendation:**
Remove the diagnostic script from production entirely:

```bash
# RECOMMENDED: Delete the file
rm scripts/debug/diagnostic.php

# Or move to a non-web-accessible location
mv scripts/debug/diagnostic.php scripts/internal/diagnostic.php
```

If debugging capability is absolutely needed, implement strict access controls:

```php
<?php
// scripts/debug/diagnostic.php (if retained)
declare(strict_types=1);

// Require admin authentication
session_start();
if (!isset($_SESSION['is_admin']) || $_SESSION['is_admin'] !== true) {
    http_response_code(403);
    exit('Forbidden');
}

// Restrict to localhost only
$allowedIps = ['127.0.0.1', '::1'];
if (!in_array($_SERVER['REMOTE_ADDR'] ?? '', $allowedIps, true)) {
    http_response_code(403);
    exit('Forbidden');
}

// ... rest of diagnostic code
```

**Fix Priority:** IMMEDIATE

#### C2: Session Fixation via Session Regeneration Timing

**Severity:** CRITICAL  
**Location:** `config/session.php`, `includes/auth.php:login_user()`  
**CWE:** CWE-384 (Session Fixation)

**Description:**
The session regeneration occurs AFTER authentication succeeds and AFTER the session has been used throughout the request. The vulnerable flow:

1. `config/session.php` starts session on every request (line 22-28)
2. Session validation runs, binding fingerprint to existing session
3. User submits login credentials with potentially attacker-set session ID
4. `login_user()` calls `session_regenerate_id(true)` (line 795)
5. Privileged session data (`user_id`, `public_user_id`) is set

An attacker can set a known session ID in the victim's browser, and when the victim logs in, the session data migration may not be atomic.

**Attack Scenario:**
```
1. Attacker visits site, obtains session ID: ABC123
2. Attacker injects cookie into victim's browser: PHPSESSID=ABC123
   (via XSS on related domain, network attack, or physical access)
3. Victim logs in - authentication succeeds with attacker's session
4. Session regenerates, but there's a window where session data
   could be accessed or the regeneration could fail
5. Attacker may retain ability to access session data
```

**Current Code (vulnerable pattern):**
```php
// config/session.php - Lines 22-28
if (session_status() !== PHP_SESSION_ACTIVE && !session_start()) {
    throw new RuntimeException('Session failed to start');
}
// ... session fingerprint validation ...

// includes/auth.php - login_user() function - Line 795
function login_user(PDO $pdo, string $identifier, string $password): bool|string
{
    ensure_session_started(); // Uses potentially attacker-set session
    // ... authentication checks ...
    
    // Regenerates AFTER authentication, but session was already active
    session_regenerate_id(true);
    
    // Sets privileged data
    $_SESSION['user_id'] = (int)$user['id'];
    $_SESSION['public_user_id'] = (string)$user['public_id'];
    // ...
}
```

**Recommendation:**
Regenerate session ID IMMEDIATELY before setting any privileged data:

```php
// includes/auth.php - login_user() function
function login_user(PDO $pdo, string $identifier, string $password): bool|string
{
    // Start session for reading/writing
    ensure_session_started();
    
    // ... authentication logic (unchanged) ...
    
    if (!$user || !$valid) {
        return false;
    }
    
    // CRITICAL FIX: Regenerate BEFORE setting privileged session data
    session_regenerate_id(true);
    
    // Clear ALL old session data to prevent data leakage
    $oldSession = $_SESSION ?? [];
    $_SESSION = [];
    
    // Set fresh session data
    $_SESSION['user_id'] = (int)$user['id'];
    $_SESSION['public_user_id'] = (string)$user['public_id'];
    $_SESSION['username'] = $user['username'];
    $_SESSION['session_version'] = (int)($user['session_version'] ?? 1);
    $_SESSION['ip'] = $ip;
    $_SESSION['created_at'] = time();
    $_SESSION['last_activity'] = time();
    $_SESSION['last_regen'] = time();
    
    // Optionally preserve non-privileged data (e.g., shopping cart)
    // $_SESSION['cart'] = $oldSession['cart'] ?? null;
    
    clear_failed_attempts($pdo, $attemptKey);
    logActivity(LOG_LOGIN_SUCCESS);
    return true;
}
```

**Fix Priority:** HIGH

#### C3: Missing Ownership Verification on Image Serving

**Severity:** CRITICAL  
**Location:** `public/serve_image.php`  
**CWE:** CWE-284 (Improper Access Control), CWE-599 (Missing Reference Check)

**Description:**
The `serve_image.php` endpoint authenticates users but does not verify that the requesting user owns the image they're accessing. Any authenticated user can access any other user's profile image by guessing or enumerating filenames.

**Current Code:**
```php
// public/serve_image.php - Lines 18-25
require_once __DIR__ . '/../includes/auth.php';
require_login(); // Only checks if user is logged in

$requested = $_GET['file'] ?? '';
$filename = basename((string) $requested);

// No ownership check - any user can access any image!
```

**Attack Scenario:**
```
1. Attacker creates account and logs in
2. Attacker enumerates profile image filenames:
   - Pattern: avatar_[40-hex-chars]_original.jpg
3. Attacker writes script to download all accessible images:
   for i in {1..10000}; do
     curl -b cookies "https://target/serve_image.php?file=avatar_$(printf '%040x' $i)_*.jpg"
   done
4. Attacker builds database of all user profile images
5. Enables targeted social engineering or reconnaissance
```

**Recommendation:**
Add ownership verification:

```php
// public/serve_image.php - Add after require_login()
require_login();

$requested = $_GET['file'] ?? '';
$filename = basename((string) $requested);

// Validate filename format
if (!preg_match('/^[a-zA-Z0-9._\-]+$/', $filename)) {
    http_response_code(400);
    logSecurityEvent(LOG_SUSPICIOUS, 'Invalid image filename: ' . substr($filename, 0, 50));
    exit('Invalid filename.');
}

// Get database connection
$pdo = $GLOBALS['pdo'] ?? null;
if (!$pdo) {
    require __DIR__ . '/../config/db.php';
    $pdo = $GLOBALS['pdo'];
}

// Check ownership - is this the viewer's image or the default?
$viewerId = (int) $_SESSION['user_id'];
$isDefaultImage = ($filename === 'default_agent.png');

if (!$isDefaultImage) {
    // Look up who owns this image
    $stmt = $pdo->prepare("SELECT id FROM users WHERE profile_image_path = :filename LIMIT 1");
    $stmt->execute(['filename' => $filename]);
    $owner = $stmt->fetch(PDO::FETCH_ASSOC);
    
    $imageOwnerId = $owner ? (int) $owner['id'] : null;
    
    // Deny access if user doesn't own the image
    if ($imageOwnerId === null || $viewerId !== $imageOwnerId) {
        // Log the access attempt for security monitoring
        logSecurityEvent(LOG_SUSPICIOUS, 
            'User ' . $viewerId . ' attempted to access image ' . $filename . 
            ' owned by ' . ($imageOwnerId ?? 'unknown'));
        
        // Return default image instead of 404 to avoid enumeration
        $filename = 'default_agent.png';
    }
}

// Continue with existing file serving logic...
```

**Fix Priority:** HIGH

#### H1: No Rate Limiting on Image Serving Endpoint

**Severity:** HIGH  
**Location:** `public/serve_image.php`  
**CWE:** CWE-770 (Allocation of Resources Without Limits)

**Description:**
The `serve_image.php` endpoint has no rate limiting, enabling:
1. Brute-force enumeration of all profile images
2. Denial of Service through repeated requests
3. Using the endpoint as an oracle for user enumeration

**Recommendation:**
Add per-user rate limiting similar to login/search:

```php
// public/serve_image.php - Add after require_login()
$viewerId = (int) $_SESSION['user_id'];
$clientIp = get_client_ip();
$now = time();

// Rate limit key: per-user with IP component
$rateLimitKey = 'img:' . $viewerId . ':' . substr(hash('sha256', $clientIp), 0, 8);

// Check rate limit (60 requests per minute)
$stmt = $pdo->prepare("
    SELECT attempts, last_attempt, locked_until 
    FROM login_attempts 
    WHERE ip = :key
");
$stmt->execute(['key' => $rateLimitKey]);
$row = $stmt->fetch(PDO::FETCH_ASSOC);

if ($row) {
    $lastAttempt = (int) $row['last_attempt'];
    $attempts = ($lastAttempt < $now - 60) ? 0 : (int) $row['attempts'];
    $lockedUntil = (int) $row['locked_until'];
    
    if ($lockedUntil > $now) {
        logSecurityEvent(LOG_SUSPICIOUS, 'Image rate limit exceeded for user ' . $viewerId);
        http_response_code(429);
        header('Retry-After: ' . ($lockedUntil - $now));
        exit('Too many requests.');
    }
    
    if ($attempts >= 60) {
        // Lock for 1 minute
        $pdo->prepare("
            UPDATE login_attempts 
            SET locked_until = :until 
            WHERE ip = :key
        ")->execute(['until' => $now + 60, 'key' => $rateLimitKey]);
        
        logSecurityEvent(LOG_SUSPICIOUS, 'Image rate limit triggered for user ' . $viewerId);
        http_response_code(429);
        header('Retry-After: 60');
        exit('Too many requests.');
    }
}

// Record this request
$pdo->prepare("
    INSERT INTO login_attempts (ip, attempts, last_attempt)
    VALUES (:key, 1, :now)
    ON DUPLICATE KEY UPDATE
        attempts = IF(last_attempt < :window, 1, attempts + 1),
        locked_until = IF(IF(last_attempt < :window, 1, attempts + 1) >= 60, :now + 60, locked_until),
        last_attempt = :now
")->execute([
    'key' => $rateLimitKey,
    'now' => $now,
    'window' => $now - 60
]);
```

#### H2: Incomplete CSRF Protection Coverage

**Severity:** HIGH  
**Location:** Multiple endpoints  
**CWE:** CWE-352 (Cross-Site Request Forgery)

**Description:**
While the CSRF implementation in `includes/csrf.php` is excellent (HMAC-bound tokens, token pool, origin checking), not all state-changing endpoints have been verified to use it consistently.

**Verified Protected Endpoints:**
| Endpoint | CSRF Protection | Status |
|----------|----------------|--------|
| `/login.php` | `verifyCsrf()` | ✅ |
| `/register.php` | `verifyCsrf()` | ✅ |
| `/payment_page.php` | `verifyCsrf()` | ✅ |
| `/change_password.php` | `verifyCsrf()` | ✅ |
| `/profile.php` | `verifyCsrf()` | ✅ |
| `/logout.php` | `verifyCsrf()` on POST only | ⚠️ |

**Recommendation:**
Create automated verification to ensure all POST endpoints have CSRF protection:

```bash
#!/bin/bash
# scripts/security/verify-csrf.sh

echo "Checking CSRF protection on all PHP endpoints..."
FAILED=0

for file in public/*.php; do
    # Check if file handles POST requests
    if grep -q 'REQUEST_METHOD.*POST' "$file" 2>/dev/null; then
        # Check if it has CSRF verification
        if ! grep -q 'verifyCsrf\|verifyCsrfAjax' "$file" 2>/dev/null; then
            echo "❌ MISSING CSRF: $file"
            FAILED=1
        else
            echo "✅ PROTECTED: $file"
        fi
    fi
done

# Check includes/ for POST handlers
for file in includes/*_logic.php includes/process_*.php; do
    if grep -q 'REQUEST_METHOD.*POST\|$_POST' "$file" 2>/dev/null; then
        if ! grep -q 'verifyCsrf\|verifyCsrfAjax' "$file" 2>/dev/null; then
            echo "❌ MISSING CSRF: $file"
            FAILED=1
        fi
    fi
done

if [ $FAILED -eq 1 ]; then
    echo ""
    echo "ERROR: Some endpoints are missing CSRF protection!"
    exit 1
fi

echo ""
echo "All endpoints have CSRF protection."
exit 0
```

Add as pre-commit hook:
```bash
# .git/hooks/pre-commit
chmod +x scripts/security/verify-csrf.sh
scripts/security/verify-csrf.sh || exit 1
```

#### H3: Insecure Default in .env.example

**Severity:** HIGH  
**Location:** `docker/.env.example`  
**CWE:** CWE-1188 (Insecure Default Initialization of Resource)

**Description:**
The `.env.example` file contains a specific SESSION_SECRET value:

```dotenv
SESSION_SECRET=replace-with-at-least-32-random-characters#dd6d68516c115e146f243aaadf93e8d9b885418e839dbd3cfaa2da7755cfb775
```

Risks:
1. Developers may copy `.env.example` without changing the secret
2. The specific hash could be accidentally committed to `.env`
3. Same secret across development environments enables session hijacking

**Recommendation:**
Use an obvious placeholder that cannot be mistaken for a valid value:

```dotenv
# docker/.env.example - Change to:
SESSION_SECRET=REPLACE_WITH_64_HEX_CHARS_FROM_OPENSSL_RAND_HEX_32
```

Add validation that fails loudly:

```php
// config/session.php - Enhance existing validation
$secret = (string) ($_ENV['SESSION_SECRET'] ?? getenv('SESSION_SECRET') ?: '');

$invalidPatterns = [
    'REPLACE_WITH',
    'CHANGE_ME',
    'YOUR_',
    'EXAMPLE',
    'replace-with',
];

$isPlaceholder = false;
foreach ($invalidPatterns as $pattern) {
    if (stripos($secret, $pattern) !== false) {
        $isPlaceholder = true;
        break;
    }
}

if ($secret === '' || $isPlaceholder || strlen($secret) < 32) {
    http_response_code(500);
    error_log('CRITICAL: SESSION_SECRET is not configured or uses placeholder value');
    exit('Server misconfiguration: SESSION_SECRET not properly set. See docs.');
}
```

#### H4: TRUSTED_PROXIES Validation Allows Dangerous Configurations

**Severity:** HIGH  
**Location:** `includes/request.php:get_trusted_proxy_ips()`  
**CWE:** CWE-290 (Authentication Bypass by Spoofing)

**Description:**
The `get_trusted_proxy_ips()` function validates IP format but doesn't prevent dangerous configurations like CIDR ranges that could trust all IPs.

**Current Code:**
```php
function get_trusted_proxy_ips(): array
{
    $raw = trim((string) getenv('TRUSTED_PROXIES'));
    if ($raw === '') {
        return [];
    }
    
    $trusted = [];
    foreach (explode(',', $raw) as $candidate) {
        $ip = trim($candidate);
        if (filter_var($ip, FILTER_VALIDATE_IP, FILTER_FLAG_IPV4 | FILTER_FLAG_IPV6)) {
            $trusted[] = $ip;
        }
    }
    return $trusted;
}
```

**Attack Scenario:**
If an attacker can influence environment variables (through SSRF, container escape, etc.):
```
TRUSTED_PROXIES=0.0.0.0/0  # If CIDR were allowed
# OR
TRUSTED_PROXIES=10.0.0.0/8  # Trust entire private network
```

This would allow spoofing `X-Forwarded-Proto` to bypass HTTPS enforcement.

**Recommendation:**
Add strict validation:

```php
function get_trusted_proxy_ips(): array
{
    static $cached = null;
    if ($cached !== null) {
        return $cached;
    }

    $raw = trim((string) getenv('TRUSTED_PROXIES'));
    if ($raw === '') {
        $cached = [];
        return $cached;
    }

    $trusted = [];
    foreach (explode(',', $raw) as $candidate) {
        $ip = trim($candidate);
        
        // Reject empty entries
        if ($ip === '') {
            continue;
        }
        
        // SECURITY: Reject CIDR notation - only allow specific IPs
        if (str_contains($ip, '/')) {
            error_log('SECURITY: TRUSTED_PROXIES rejects CIDR notation: ' . $ip);
            continue;
        }
        
        // Validate IP format
        if (filter_var($ip, FILTER_VALIDATE_IP, FILTER_FLAG_IPV4 | FILTER_FLAG_IPV6)) {
            // SECURITY: Warn about private/reserved ranges
            if (
                str_starts_with($ip, '127.') ||
                str_starts_with($ip, '::1') ||
                str_starts_with($ip, '10.') ||
                str_starts_with($ip, '172.16.') ||
                str_starts_with($ip, '172.17.') ||
                str_starts_with($ip, '172.18.') ||
                str_starts_with($ip, '172.19.') ||
                str_starts_with($ip, '172.2') ||
                str_starts_with($ip, '172.30.') ||
                str_starts_with($ip, '172.31.') ||
                str_starts_with($ip, '192.168.')
            ) {
                error_log('WARNING: TRUSTED_PROXIES includes private IP: ' . $ip);
            }
            $trusted[] = $ip;
        } else {
            error_log('SECURITY: TRUSTED_PROXIES contains invalid IP: ' . $ip);
        }
    }

    $cached = array_values(array_unique($trusted));
    return $cached;
}
```

#### H5: No CSP Report URI for Security Monitoring

**Severity:** HIGH  
**Location:** `includes/header.php:build_csp()`  
**CWE:** CWE-776 (Reliance on Unspecified Behavior)

**Description:**
The Content-Security-Policy is well-configured but lacks a `report-uri` or `report-to` directive. Without reporting, the team cannot detect XSS probe attempts or identify CSP violations.

**Current Code:**
```php
function build_csp(string $nonce): string
{
    $directives = [
        "default-src 'self'",
        "script-src 'self' 'nonce-{$nonce}' 'strict-dynamic'",
        "style-src 'self'",
        // ... no report-uri directive
    ];
    return implode('; ', $directives);
}
```

**Recommendation:**
Add CSP reporting:

```php
function build_csp(string $nonce): string
{
    $reportUri = getenv('CSP_REPORT_URI') ?: '/api/csp-report';
    
    $directives = [
        "default-src 'self'",
        "script-src 'self' 'nonce-{$nonce}' 'strict-dynamic'",
        "style-src 'self'",
        "img-src 'self' data: blob:",
        "font-src 'self' data:",
        "connect-src 'self'",
        "frame-src 'none'",
        "object-src 'none'",
        "frame-ancestors 'none'",
        "base-uri 'self'",
        "form-action 'self'",
        "manifest-src 'self'",
        "worker-src 'self'",
        "report-uri {$reportUri}",
        "report-to csp-endpoint",
    ];
    
    if (is_secure_request()) {
        $directives[] = 'upgrade-insecure-requests';
        $directives[] = 'block-all-mixed-content';
    }
    
    return implode('; ', $directives);
}
```

Create report endpoint:

```php
<?php
// public/api/csp-report.php
declare(strict_types=1);

require_once __DIR__ . '/../../includes/header.php';
require_once __DIR__ . '/../../config/db.php';
require_once __DIR__ . '/../../includes/sanitize.php';
require_once __DIR__ . '/../../includes/logger.php';

if ($_SERVER['REQUEST_METHOD'] !== 'POST') {
    http_response_code(405);
    exit('Method not allowed');
}

$report = file_get_contents('php://input');
$data = json_decode($report, true);

if ($data && isset($data['csp-report'])) {
    $reportData = $data['csp-report'];
    
    // Log CSP violation for security monitoring
    $violation = sprintf(
        'CSP:%s:%s:%s',
        $reportData['violated-directive'] ?? 'unknown',
        $reportData['blocked-uri'] ?? 'unknown',
        substr($reportData['source-file'] ?? 'unknown', 0, 100)
    );
    logSecurityEvent(LOG_XSS_PROBE, $violation);
    
    // Store in database for analysis
    try {
        $stmt = $pdo->prepare("
            INSERT INTO csp_reports (
                report_data, 
                client_ip, 
                user_agent,
                created_at
            ) VALUES (:report, :ip, :ua, NOW())
        ");
        $stmt->execute([
            'report' => substr($report, 0, 2000),
            'ip' => get_client_ip(),
            'ua' => substr($_SERVER['HTTP_USER_AGENT'] ?? '', 0, 255),
        ]);
    } catch (Throwable $e) {
        // Non-critical - logging already done
    }
}

http_response_code(204);
```

#### H6: Database Connection Not Encrypted

**Severity:** HIGH  
**Location:** `config/db.php`  
**CWE:** CWE-319 (Cleartext Transmission of Sensitive Information)

**Description:**
The database connection uses plain TCP without SSL/TLS encryption:

```php
$dsn = "mysql:host={$host};dbname={$db};charset=utf8mb4";
$pdo = new PDO($dsn, $user, $pass, $options);
```

While Docker's internal network provides some isolation, encryption is still important for:
1. Defense in depth against container network sniffing
2. Compliance requirements (PCI-DSS, HIPAA, SOC2)
3. Future migration to external database services

**Recommendation:**
Enable MySQL SSL:

```php
// config/db.php
$host = getenv('MYSQL_HOST');
$db   = getenv('MYSQL_DATABASE');
$user = getenv('MYSQL_USER');
$pass = getenv('MYSQL_PASSWORD');
$sslMode = getenv('MYSQL_SSL_MODE') ?: 'required';

$dsn = "mysql:host={$host};dbname={$db};charset=utf8mb4";

$options = [
    PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,

// Add SSL options if enabled

    $caPath = getenv('MYSQL_SSL_CA') ?: '/etc/ssl/certs/ca-certificates.crt';
    $certPath = getenv('MYSQL_SSL_CERT') ?: null;
    $keyPath = getenv('MYSQL_SSL_KEY') ?: null;
    
    if (file_exists($caPath)) {
        $options[PDO::MYSQL_ATTR_SSL_CA] = $caPath;
    }
    if ($certPath && file_exists($certPath)) {
        $options[PDO::MYSQL_ATTR_SSL_CERT] = $certPath;
    }
    if ($keyPath && file_exists($keyPath)) {
        $options[PDO::MYSQL_ATTR_SSL_KEY] = $keyPath;
    }
    $options[PDO::MYSQL_ATTR_SSL_VERIFY_SERVER_CERT] = ($sslMode === 'verify_ca' || $sslMode === 'verify_identity');
}

$pdo = new PDO($dsn, $user, $pass, $options);

// Verify SSL is active (log warning if not)
if ($sslMode !== 'disabled') {
    try {
        $stmt = $pdo->query("SHOW STATUS LIKE 'Ssl_version'");
        $sslStatus = $stmt->fetch(PDO::FETCH_ASSOC);
        if (empty($sslStatus['Value'])) {
            error_log('WARNING: MySQL SSL connection requested but not established');
        }
    } catch (Throwable $e) {
        // Non-fatal - connection still works
    }
```

#### H7: Hardcoded Seed User Password Hashes

**Severity:** HIGH  
**Location:** `docker/setup.sh`  
**CWE:** CWE-798 (Use of Hard-coded Credentials), CWE-259 (Use of Hard-coded Password)

**Description:**
The setup script contains hardcoded bcrypt hashes for seed users:

```bash
INSERT INTO users (username, email, password_hash, ...)
VALUES
  ('nishanth', 'nishanth@iith.in', '$2y$10$p9hl/NUNL7WTExKoI34aqOfd5Rgv2hUinHSCfolpjjZof.QZOrisu', ...),
```

Issues:
1. Hashes are in version control - can be cracked offline
2. Same hashes across all deployments
3. The "trudy" account (common attacker name) suggests a backdoor
4. Anyone with repo access knows valid credentials if they crack the hash

**Recommendation:**
Generate unique passwords per deployment:

```bash
# docker/setup.sh - Replace hardcoded section

# Generate random passwords for seed users
generate_hash() {
    local pass="$1"
    docker compose exec -T app php -r "echo password_hash('$pass', PASSWORD_BCRYPT, ['cost' => 10]);"
}

# Create credentials file for team (store securely, don't commit)
CREDENTIALS_FILE="/tmp/seed_user_credentials_$(date +%Y%m%d).txt"
echo "Seed User Credentials - $(date)" > "$CREDENTIALS_FILE"
echo "Store this file securely and delete after distribution" >> "$CREDENTIALS_FILE"
echo "" >> "$CREDENTIALS_FILE"

# Generate for each seed user
for user in nishanth tejas divyansh harshavardhan vrishin trudy; do
    PASS=$(openssl rand -base64 16 | tr -d '=')
    HASH=$(generate_hash "$PASS")
    echo "$user: $PASS" >> "$CREDENTIALS_FILE"
    
    # Store hash in variable for SQL insert
    case $user in
        nishanth) NISHANTH_HASH="$HASH" ;;
        tejas) TEJAS_HASH="$HASH" ;;
        # ... etc
    esac
done

echo "" >> "$CREDENTIALS_FILE"
echo "IMPORTANT: Delete this file after distributing to team" >> "$CREDENTIALS_FILE"

# Insert users with generated hashes
mysql ... <<SQL
INSERT INTO users (username, email, password_hash, balance_paise, bio)
VALUES
  ('nishanth', 'nishanth@iith.in', '$NISHANTH_HASH', 10000, 'Seed account'),
  ('tejas', 'tejas@iith.in', '$TEJAS_HASH', 10000, 'Seed account'),
  -- etc
ON DUPLICATE KEY UPDATE
  password_hash = VALUES(password_hash),
  updated_at = CURRENT_TIMESTAMP;
SQL

echo "[setup] Seed user credentials written to: $CREDENTIALS_FILE"
```

```php
function is_password_breached(string $password): bool
{
    $sha1 = strtoupper(sha1($password));
    $prefix = substr($sha1, 0, 5);
    $suffix = substr($sha1, 5);
    
    $response = @file_get_contents("https://api.pwnedpasswords.com/range/{$prefix}");
    if ($response === false) {
        return false; // Fail open - API unavailable

    foreach (explode("\r\n", $response) as $line) {

        if (strtoupper($hashSuffix) === $suffix && (int) $count > 0) {
            logSecurityEvent(LOG_SUSPICIOUS, 'Breached password attempted');
            return true;
        }
    }
    
    return false;
}
```

```javascript
(function() {
    const WARNING_SECONDS = 300; // 5 minutes before timeout
    const TIMEOUT_SECONDS = 1800; // 30 minutes
    
    let lastActivity = Date.now();
    
    ['mousedown', 'keydown', 'scroll', 'touchstart'].forEach(event => {
        document.addEventListener(event, () => { lastActivity = Date.now(); }, true);
    });

        const inactiveTime = Math.floor((Date.now() - lastActivity) / 1000);
        const remainingTime = TIMEOUT_SECONDS - inactiveTime;

            showTimeoutWarning(remainingTime);
        } else if (remainingTime <= 0) {
            window.location.href = '/confirm_logout.php?reason=timeout';
        }
    }, 60000);
    
    function showTimeoutWarning(seconds) {
        // Show Bootstrap modal with countdown
        const modal = document.getElementById('session-timeout-modal');
        if (modal && !modal.classList.contains('show')) {
            document.getElementById('timeout-countdown').textContent = seconds;
            new bootstrap.Modal(modal).show();

})();
```
